# pirc

起動中の pi TUI セッションをブラウザから閲覧・操作するアプリケーションです。認証は提供しないため、外部公開時は reverse proxy でアクセスを制限してください。

## 特徴

PC で動かしている pi を、スマートフォンからも確認・操作できます。携帯回線で長時間開いておけるよう、不要な本文や詳細を繰り返し送らないことを重視しています。

### 必要な情報だけを受け取る

- **ツール詳細は開いたときに取得**。普段はコマンドや変更量などの概要を表示し、大きな引数・ファイル内容・実行結果は展開時に読み込みます。実行中の詳細も、開いているツールだけを追跡します。
- **更新は差分で配信し、通信を圧縮**。生成のたびに会話全体やツール出力全文を送り直さず、取得済みの確定した詳細も再利用します。
- **見ていないタブへの配信を抑制**。タブが非表示のまま30秒経つとセッション更新の購読を止め、戻ったときに最新状態へ追いつきます。表示されたままフォーカスが外れただけでは止まりません。
- **長い履歴は段階的に取得**。最初から全履歴を読み込まず、古い履歴を追加で取得できます。セッション一覧にも、会話本文を更新のたびに流しません。

### TUI の続きを別端末から

- **起動中の pi に接続**。TUI を使い続けながら、ブラウザからメッセージ送信・中断・モデル変更・保存済みセッションへの切替ができます。一時的に接続が切れても、再接続後に同期します。
- **複数セッションをまとめて確認**。接続中のセッションを一覧から選べるほか、複数カラムに並べて進行状況を見られます。Tool・Thinking・System の表示はカラムごとに切り替えられます。
- **生成ファイルもブラウザで確認**。Markdown のリンク・画像が pi 側のローカルパスでも取得でき、画像や PDF を対応ブラウザ内で閲覧できます。メッセージは元の Markdown のままコピーできます。

## 構成と準備

- `api/`: 共有プロトコル・RPC クライアント
- `server/`: Deno 中継サーバー
- `pi-extension/`: pi セッションとの接続
- `frontend/`: ブラウザ UI

Node 22.19 以降、Deno 2.x、pnpm が必要です。まずリポジトリ直下で `pnpm install` を実行してください。

## pi-extension のインストール

`pi install git:github.com/ibuki2003/pirc` を実行します。ローカルの作業ツリーから導入する場合は、リポジトリ直下で `pi install "$(pwd)/pi-extension"` を実行します。接続先の既定値は `ws://localhost:8787` です。変更する場合は `~/.pi/agent/pirc.json` に `{"host":"wss://example.com"}` を保存してください（pi の agent directory を変更している場合はそのディレクトリ）。一時的に使う場合は `pi -e ./pi-extension/src/index.ts` でも起動できます。

## backend

`cd server && deno task start` で起動します。既定のポートは 8787、静的ファイルの配信元は `../frontend/dist` です。必要に応じて `PIRC_PORT` と `PIRC_STATIC_DIR` を設定できます。

## frontend

- 開発: backend を起動したうえで、リポジトリ直下から `pnpm -F frontend dev`
- ビルド: `pnpm -F frontend prepare && pnpm -F frontend build`（生成物は `frontend/dist/`）
