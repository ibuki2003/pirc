# 完了通知

接続中のすべての pi セッションで AI の作業が終わったとき、ntfy.sh に通知する独立した Deno プログラムです。
タイトルは `[pi] ready (ディレクトリ名@ホスト名)`、本文は現在の枝にある最後の assistant メッセージのテキストです。ntfy の添付ファイル扱いにならないよう、長い本文は UTF-8 で4,096バイト以内に省略します。

対象セッションで完了前10秒以内に操作があれば通知しません。それ以外は完了後30秒待ち、その間に操作があれば通知を取り消します。TUI ではキー入力・貼り付け、pirc では入力・クリック・ホイール・タッチスクロールが対象です。TUI のマウススクロールや、操作せずに読んでいる状態は検知できません。返答の短さやツール使用の有無では通知を除外しません。

時間は環境変数で変更できます（単位は秒）。`PIRC_NOTIFY_ACTIVE_SECONDS` は完了前の活動判定期間（既定 `10`、`0` で無効）、`PIRC_NOTIFY_DELAY_SECONDS` は完了後の待機時間（既定 `30`、`0` で即時）です。待機中に notifier または対象の pi が切断すると、その通知は破棄します。

```sh
cd notifier
NTFY_TOPIC=自分専用の推測されにくいトピック deno task start
```

`PIRC_SERVER_URL` で接続先を変更できます（既定値 `ws://localhost:8787/api/notify`）。以前の `/api/ws` はブラウザ専用で、通知プログラムからは接続できません。外部公開する場合、server 側のアクセス制御は reverse proxy 等で行ってください。ntfy.sh のトピックを知る人は通知を閲覧できます。

起動前・切断中の完了は遡って通知しません。通信失敗時の通知の永続化・再送も行いません。
